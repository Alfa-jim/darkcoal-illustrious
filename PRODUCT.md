# Darkcoal Illustrious playground

## Register
Product: a generation tool with editable settings, not a marketing site.

## Target users
The endpoint owner comparing compatible Illustrious checkpoints and sampling settings on RunPod.

## Product purpose
Select a checkpoint and optional acceleration, submit a generation, inspect the image, and preserve useful settings. Keep the existing endpoint credentials, reference uploads, presets, and request workflow compatible.

## Brand personality
Direct, calm, practical. Preserve the existing dark interface and familiar controls.

## Design principles
Use explicit model names and versions. Keep acceleration optional. Make settings editable and persist choices without submitting on refresh. Avoid unsupported speed or quality guarantees. Explain worker loading delays near model selection.

## Accessibility
Use native controls and visible labels. Retain the existing responsive layout and keyboard behavior.
